# Hospital Directory — نسخة للمراجعة قبل النشر

## الملفات
- `index.html`: الموقع كامل في ملف واحد، بتصميم الموقع الأصلي وألوانه. يمكن رفعه إلى الاستضافة لاحقًا.
- `Code.gs`: كود Google Apps Script المقترح لإرجاع بيانات الشيت، بما فيها المبنى.
- `Directory-Template.csv`: عناوين الأعمدة فقط، دون أرقام تجريبية.

## ما تم تعديله
- استبدال اسم وشعار A3 بهوية Hospital Directory وأيقونة مبنى عامة، وليست شعارًا رسميًا للمستشفى.
- اختيار Main Hospital أو KACOLD أو East Wing أو All buildings، ثم القسم داخل المبنى. قائمة الأقسام تُقرأ تلقائيًا من الصفوف المصنفة كأرقام قسم، ولا تحتاج تعديل الكود عند إضافة قسم جديد.
- حفظ آخر مبنى وآخر قسم مختار داخل كل مبنى على المتصفح نفسه تلقائيًا. لا يحتاج حسابًا؛ لا ينتقل إلى جهاز آخر أو نطاق جديد. مسح بيانات الموقع يمسح الاختيار والمفضلة.
- أول زيارة تعرض جميع المباني. لا نفترض مبنى المستخدم أو مكان الأرقام القديمة.
- البحث يبقى داخل المبنى والقسم المختارين افتراضيًا، مع خدمات المبنى والمستشفى المشتركة. تفعيل Search all buildings يوسّع البحث عند كتابة كلمة، ولا يغيّر المبنى أو القسم المحفوظين. التفعيل مؤقت للجلسة.
- الخدمات المشتركة تظهر في كل مبنى. تظهر تسمية المبنى على كل بطاقة.
- المفضلة وحجم الخط مستمران. تُرحّل مفاتيح التخزين القديمة على نفس النطاق؛ لذلك بقيت أسماء تقنية قديمة داخل جزء ترحيل البيانات فقط، وليست أسماء ظاهرة للمستخدم.
- البحث يدعم أجزاء الكلمات وعدة كلمات والبحث بالعربية والأرقام العربية وكلمات بديلة.
- البيانات المحفوظة تظهر عند فشل التحديث مع توضيح أنها قديمة وتاريخ آخر تحديث ناجح إن كان معروفًا.
- إعادة محاولة تلقائية واحدة، ثم زر إعادة محاولة واضح، بدل بقاء مربعات التحميل بلا نهاية.
- إزالة قسم أجهزة وطابعات A3 وبيانات الدخول المخزنة فيه من النسخة العامة. إذا كانت بيانات الدخول القديمة حقيقية، يجب تغييرها؛ حذفها من هذه النسخة لا يزيلها من النسخة القديمة أو سجل GitHub.
- اسم المطور باقٍ في الإعدادات فقط. لم يتغير الرابط ولم يُنشر شيء.
- إعداد Google Analytics الأصلي بقي كما هو.

## ربط الشيت — المطلوب قبل التشغيل الفعلي
1. احتفظ بنسخة من Apps Script الحالي قبل استبداله؛ الكود الحالي على حسابك لم يكن متاحًا للمراجعة.
2. في ورقة الأرقام الموجودة، أبق أعمدة `category` و`service` و`extension`، وأضف عمود `building`. لا يلزم نقل الأرقام إلى ملف شيت جديد.
3. ضع إحدى القيم التالية في building:
   - `Main Hospital`
   - `KACOLD`
   - `East Wing`
   - `Shared` لخدمة مشتركة تظهر للجميع.
   - لخدمة تخص مبنيين: `Main Hospital, KACOLD` (في نفس الخلية).
4. الخلية الفارغة أو قيمة مبنى غير معروفة تعرض Building not set. تظهر هذه السجلات في All buildings والبحث الشامل فقط؛ لا تُحذف ولا تنسب لمبنى تلقائيًا.
5. إذا اختلف رقم نفس الخدمة بين مبنيين، خصص صفًا لكل رقم ومبنى. لا تستخدم Shared إلا إذا كان الرقم نفسه يخدم كل المباني.
6. العمود الاختياري `aliases` للكلمات البديلة، مثل الاسم المختصر أو العربي. والعمود الاختياري `id` لمعرف فريد ثابت يحافظ على المفضلة حتى مع تغيير اسم الخدمة أو رقمها. تجنب تكرار المعرف.
7. تم ضبط `Code.gs` على ملف الشيت الأصلي A3 Extensions ومعرف تبويبه الفعلي 0 بعد قراءة بياناته وأعمدته. يعتمد على معرف التبويب بدل اسمه، لذلك تغيير اسم الشيت أو التبويب لاحقًا لا يكسر الربط. الأعمدة الحالية A:C هي category وservice وextension، ويمكن إضافة building في D وaliases في E وid في F. لم يُعدّل الشيت الفعلي.
8. يقرأ السكربت الأعمدة بحسب العنوان، ويحافظ على الأرقام كما تظهر في الشيت، ولا يكتب في الخلايا.
9. راجع نشر Apps Script كـ Web app وصلاحيات الوصول وفق نطاق نشر الدليل المعتمد. الموقع الحالي يستخدم طلبًا بلا تسجيل دخول؛ إذا لم يكن مسموحًا إتاحة بيانات الدليل بهذه الطريقة، يلزم تصميم دخول مناسب بدل جعل الشيت عامًا. لا تنشر كلمات مرور أو بيانات مرضى.
10. عند تحديث النشر الموجود، استخدم نسخة جديدة في النشر نفسه للمحافظة على رابط exec، ثم اختبره. إذا تغيّر رابط النشر، غيّر `APPS_SCRIPT_URL` في index.html.
11. الموقع يحتفظ برابط Apps Script القديم كما هو. إصلاح الواجهة لا يزيل خطأ 403؛ يجب إصلاح صلاحية/نشر خدمة البيانات ثم اختبار بيانات حقيقية.

## حالة النسخة
- هذه حزمة محلية جاهزة للمراجعة، وليست تحديثًا للموقع المنشور.
- اختُبرت وظائف الواجهة ببيانات اختبار منفصلة لا توجد في index.html أو ملف القالب.
- لم يُتحقق من الاتصال الحي بعد إصلاح Apps Script ولم تُحدد مباني الأرقام الفعلية؛ عُثر على الشيت وقُرئت عناوينه؛ المتبقي مراجعة إعدادات/كود السكربت الحالي وتحديد المباني الصحيحة.
- تغيير الرابط والـQR مؤجل حسب طلبك.


## إضافة الأقسام والغرف (الإصدار المحدّث)
ترتيب الأعمدة في القالب الجديد يحافظ على أول ثلاثة أعمدة الأصلية:

| العمود | العنوان | الاستخدام |
|---|---|---|
| A | category | تصنيف مثل Rooms أو Pharmacy |
| B | service | اسم الخدمة أو هاتف الغرفة |
| C | extension | التحويلة؛ تحفظ كنص عند وجود أصفار في البداية |
| D | building | Main Hospital أو KACOLD أو East Wing؛ Shared للخدمات العامة القديمة |
| E | aliases | كلمات بحث بديلة، اختياري |
| F | id | معرف ثابت وفريد للسجل، اختياري ومفضل للمفضلة |
| G | department | اسم القسم، مثل A3 أو B3 |
| H | room | رقم الغرفة، اختياري؛ لا تُدخل بيانات المرضى |
| I | scope | department أو building أو hospital |

قواعد الصفوف:
- رقم قسم أو غرفة: scope=department، مبنى واحد محدد واسم القسم؛ room عند الحاجة.
- خدمة لكل أقسام مبنى: scope=building، حدد building واترك department وroom فارغين.
- خدمة للمستشفى كامل: scope=hospital، اترك department وroom فارغين. يمكن ترك building فارغًا.
- إذا اختلف رقم الغرفة بين قسمين، استخدم صفين؛ هوية البطاقة تتضمن المبنى والقسم والغرفة. لا تتشارك المفضلة بين غرفتين لمجرد تطابق الاسم.
- تُقبل أيضًا نطاقات الظهور العربية: القسم فقط / المبنى كامل / المستشفى كامل.
- اختيار All departments يعرض أقسام المبنى كلها. لتخصيص الدليل اختر قسمًا محددًا.
- اختيار All buildings أو البحث الشامل يعرض الأقسام في مختلف المباني ويكتب مكان كل نتيجة.
- الأقسام المتطابقة في الاسم بمبنيين تبقى منفصلة. يحفظ الموقع آخر قسم في كل مبنى ويعيده عند العودة إلى ذلك المبنى.
- التوافق القديم: إذا scope فارغ ومعه department، يعد رقم قسم؛ وإن كان رقمًا بلا قسم وله مبنى فيعد خدمة مبنى؛ Shared يعد خدمة عامة. أرقام الغرف التي ينقصها القسم، أو صفوف الغرف الموسومة كخدمة عامة بالخطأ، لا تُعمم؛ تظهر في All buildings مع تنبيه للموقع غير المكتمل.
- أُضيفت الأعمدة إلى القالب والكود فقط؛ لم تُضف إلى الشيت المباشر ولم تُنسب الأرقام الحالية لأقسام أو غرف بالتخمين.

اختبار هذه الإضافة: حفظ القسم عبر إعادة الفتح وتبديل المبنى؛ غرفة 301 في أقسام مختلفة؛ خدمات القسم/المبنى/المستشفى؛ البحث الشامل باسم القسم ورقم الغرفة؛ المفضلة؛ ظهور قسم جديد من البيانات تلقائيًا؛ والبيانات المحفوظة أثناء انقطاع الخدمة. بيانات الاختبار ليست ضمن الموقع المسلّم.
