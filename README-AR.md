# Hospital Directory — المبنى ثم الجناح

النسخة تعمل مباشرة مع قوقل شيت داخل index.html دون Apps Script. افتحها أو ارفعها مكان ملف الموقع التشغيلي. أول زيارة تعرض All Hospital والخدمات وأرقام التواصل العامة. بعدها يختار المستخدم المبنى ثم الجناح أو القسم. يحفظ آخر اختيار. الغرف والتحويلات الخاصة تظهر بعد اختيار قسمها فقط.

## إضافة مبنى أو قسم بدون تعديل الكود
Buildings: building اسم المبنى / active TRUE لتفعيله. المباني الحالية Main Hospital وKACOLD وEast Wing. Shared لا يظهر في قائمة المباني لأنه نطاق خدمة عامة.
Departments: department اسم الجناح أو القسم / building مبناه من القائمة / active TRUE لتفعيله. أضف أي عدد من الأقسام كصفوف جديدة. القسم بدون مبنى لا يظهر حتى يحدد المسؤول مبناه. A3 وER وL2 الحالية بقيت بدون مبنى لأن موقعها لم يعتمد منك بعد.

## إضافة الأرقام
في التبويب الأصلي A3 Extensions، كل صف رقم واحد:
A category: التصنيف؛ B service: الاسم؛ C extension: الرقم كنص؛ D building: المبنى؛ E aliases: كلمات البحث؛ F id: معرف فريد إن توفر، لا تغير الموجود؛ G department: القسم للرقم الداخلي فقط؛ H room: الغرفة؛ I scope: hospital لخدمة أو رقم تواصل عام، department لغرف وتحويلات خاصة بالقسم، pending لإخفائه حتى مراجعته.
لرقم خاص: حدد القسم والمبنى بنفس تهجئة Departments. يمكن ترك مبنى الرقم فارغًا فقط إن كان اسم القسم فريدًا ومبناه مضبوطًا في Departments. إذا تكرر الاسم في مبنيين يلزم تحديد مبنى كل رقم.
للخدمات العامة: اترك القسم والغرفة فارغين؛ Shared للخدمة المشتركة، أو مبناها المحدد. الخدمات غير محددة المبنى تظهر في الدليل العام وفي المباني إلى أن تُراجع مواقعها.

## مشاركة الشيت مع الإدارات
أضف مسؤولًا محددًا كمحرر، وخصص له نطاق صفوف، ثم حدد من يستطيع تعديل كل نطاق من Data > Protect sheets and ranges. الحماية تمنع التعديل ولا تخفي البيانات. تخصيص الصلاحيات يحتاج إيميلات المسؤولين ولم نطبقه بعد.
لا تمنح التعديل المفتوح لكل من معه الرابط إذا أردت حصر تعديل كل قسم بنطاقه. كل إضافة صحيحة تظهر بالموقع بعد Refresh directory، وقد يحصل تأخير قصير من تخزين Google المؤقت.

لم نعدل التحويلات أو نخمن مباني الأقسام الحالية. الموقع المنشور لا يتغير إلا برفع الملف الجديد. الحزمة فيها index.html وREADME-AR.md فقط؛ التصميم والبحث والربط كاملة داخل index.html.
