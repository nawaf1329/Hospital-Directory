# Hospital Directory — نسخة التشغيل

الموقع مكتمل داخل index.html: التصميم والبحث وحفظ القسم والمفضلة والربط المباشر بقوقل شيت. لا يحتاج ملفات JS أو CSS منفصلة ولا Apps Script.

## تشغيل الموقع
فك الضغط وارفع index.html مكان الملف التشغيلي في استضافتك. إن كان الرابط الحالي يفتح test-search.html، استبدل محتواه بهذا الملف أو غيّر اسم index.html إلى test-search.html عند الرفع. الرابط الحالي لا يتغير تلقائيًا.

## البيانات
الملف يقرأ الشيت الفعلي مباشرة عبر Google Sheets، مع تخزين آخر تحديث. يتضمن نسخة فعلية من البيانات بتاريخ 11 أكتوبر 2026 ليعمل عند فشل أول اتصال؛ فشل التحديث يظهر بتاريخه ولا يُعرض كأنه تحديث حي.
لم تتغير صلاحيات مشاركة الشيت. الربط يعتمد على إمكانية القراءة العامة الموجودة حاليًا. إذا أغلقت القراءة العامة يتوقف تحديث الموقع.

التبويب الأصلي A3 Extensions (معرف 0) يحتوي الأرقام. لا تحذف عناوين الأعمدة.
التبويب Departments (معرف 701) يحتوي الأقسام: department / building / active. أضف اسم قسم جديد وTRUE في active ليظهر بعد التحديث. المبنى اختياري.

category: الفئة. service: الخدمة. extension: التحويلة كنص. building: مكان الخدمة إن عُرف. aliases: كلمات بحث. id: معرف ثابت. department: القسم للرقم الخاص فقط. room: الغرفة. scope: hospital للجميع / department للقسم / pending لحجب سجل حتى مراجعته.

الغرف والتحويلات الداخلية الخاصة تظهر للقسم المختار فقط. أرقام التواصل العامة للأقسام والخدمات تظهر للجميع بعد أرقام القسم. البحث يحافظ على نفس القاعدة. لا تضع بيانات المرضى.

المواقع غير المعروفة بقيت فارغة. أرقام Main Pharmacy ليست دليلًا كافيًا على المبنى، لذلك أزيل التخمين عنها. احتفظنا بأرقام A3 المحلية والغرف المصنفة سابقًا، ويمكنك مراجعتها أو تغيير scope إلى pending لحين اعتمادها. قائمة ER وL2 جاهزة؛ لم نختلق غرفًا أو أرقامًا خاصة لهما.

## تحديث رقم
عدّل extension في صف الخدمة، ثم افتح الموقع واضغط Refresh directory. التحديثات قد تتأخر قليلًا بسبب تخزين Google المؤقت.
